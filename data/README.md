# Данные

Файлы `*.example.csv` содержат только демонстрационные записи для smoke-тестов.
Все меры с префиксом `DEMO —` и ссылками `example.com` не являются действующими
мерами господдержки. Реальные данные импортируются отдельно после проверки
аналитиком и первоисточником.

Поля-массивы разделяются символом `|`. Пустое ограничение означает «для всех».
